## Mask-to-BBox Conversion Rules

1. Binary threshold: mask > 127 → 255 (foreground)
2. Connected components: 8-connected
3. Minimum area filter: 16 px^2 (drop annotation noise)
4. Padding: max(3 px, 0.02 * max(w, h))
5. Clamp to image boundaries
6. Max bboxes per image: 16
7. Coordinate format: YOLO center-xywh normalized

## Coordinate Convention

| Context | Format | Example |
|---|---|---|
| YOLO label file | center-xywh normalized | `3 0.512 0.487 0.234 0.156` |
| API payload (bboxes) | top-left-xywh normalized | `{"x": 0.395, "y": 0.409, "w": 0.234, "h": 0.156}` |
| Frontend SVG overlay | top-left-xywh as % of 100 | `x=39.5 y=40.9 w=23.4 h=15.6` |

## Important Caveat

Phase 10 localizer is a **supervised proof-of-concept** trained from MVTec AD ground-truth masks for selected complete categories. It is NOT evaluated under the standard unsupervised MVTec AD protocol. Reported mAP/IoU numbers are internal localization metrics on a held-out split derived from the labeled MVTec defect images and are NOT comparable to PatchCore/EfficientAD/PaDiM standard MVTec image-AUROC results.
